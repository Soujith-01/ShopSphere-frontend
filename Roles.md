ShopSphere has 5 roles, each with specific permissions:

Customer: Browse/search products, manage wishlist/cart, checkout, track orders, review and request returns.

Seller: Manage store, products, inventory, orders, returns, analytics, and settlements.

Admin: Approve sellers/products, manage users, categories, coupons, disputes, reviews, reports, and audit logs.

Support Agent: Handle customer tickets, disputes, refunds, and order issues.

Delivery Partner: View assigned deliveries and update shipment statuses.

All roles use authentication + role-based authorization, so each user can access only the features permitted for their role
